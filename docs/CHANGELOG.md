# Changelog

## Round 3 — engineering summary

The repository does not include a canonical Round 2 commitment document. To avoid rewriting project history, the three headings below map the Round 3 work to the three core delivery areas represented by the existing product and codebase.

1. **Governance scanning and brand consistency:** deterministic rule and channel checks, score/pillar response, PII redaction, optional AI provider failover, PDF/document/image ingestion, PDF layout findings, and updated claim retrieval routing.
2. **Collaborative approval and auditability:** scan versions/comments/activity, reviewer/admin approval gates, Ed25519 signatures, hash-chain verification, public-key endpoint, certificate-bearing redline exports, and tamper checks.
3. **Truth Vault and maintainable policy:** KB read/update/sync and re-audit signals, custom rules, regex safety checks, rewrite/backtest/version/rollback, analytics endpoints, 26-check backend suite, and benchmark harness.

The Chrome extension provides a configurable backend URL, active-tab selection or pasted text, channel selection, score/pillars/issues, and suggested-fix copy action. See [ROADMAP.md](ROADMAP.md) for planned Phase 4 work.
